# Шаг 2: Базовый запуск

На этом этапе мы реализовали минимально необходимый код, чтобы бот мог запуститься и ответить на команду.

## 1. Хендлер `/start` (`app/handlers/common.py`)

- Создан роутер для общих команд.
- В нем реализован простой хендлер `handle_start` для команды `/start`, который отвечает пользователю приветственным сообщением.

## 2. Точка входа (`main.py`)

- Создана основная асинхронная функция `main()`, которая является точкой входа в приложение.
- В ней настроено базовое логирование.
- **Ключевой шаг**: перед запуском бота вызывается асинхронная функция `create_tables(engine)`, которая создает все необходимые таблицы в базе данных.
- Роутер с командой `/start` регистрируется в диспетчере.
- Бот запускается в режиме long polling.

## 3. Создание таблиц (`app/db/models.py`)

- В файл с ORM-моделями добавлена асинхронная функция `create_tables`.
- Она использует `SQLAlchemy` для асинхронного подключения к БД и создания таблиц на основе всех классов, унаследованных от `Base`.

На данный момент бот является запускаемым и выполняет базовую проверку подключения к базе данных путем создания таблиц.
