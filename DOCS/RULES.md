# Правила работы с сообщениями и навигацией

## 🎯 Основные правила работы с сообщениями

### Правило 1: Переходы между сообщениями с медиа и без медиа
```
Медиа → Медиа: edit_media (перезаписываем текущее сообщение)
Медиа → Без медиа: send новое + удалить старое
Без медиа → Медиа: send новое + удалить старое  
Без медиа → Без медиа: edit (редактируем текущее сообщение)
```

### Правило 2: При send сначала приходит новое сообщение, потом удаляется старое
- ID старого сообщения сохраняется в базе и FSM
- Новое сообщение отправляется через MessageManager
- Старое сообщение удаляется только после успешной отправки нового

## 🧭 Логика навигации и возврата

### Сохранение ID старых сообщений
```python
# При переходе в редактирование из детального просмотра
await state.update_data(old_detail_message_id=callback.message.message_id)

# При переходе в редактирование из слайдера  
await state.update_data(old_slider_message_id=callback.message.message_id)
```

### Умная система возврата к исходному месту
```python
# Проверяем, откуда пользователь пришел
old_detail_msg_id = data.get("old_detail_message_id")
old_slider_msg_id = data.get("old_slider_message_id")

if old_detail_msg_id:
    # Возврат к детальному просмотру
elif old_slider_msg_id:
    # Возврат к слайдеру
else:
    # Возврат к главному меню
```

## 📱 Примеры использования

### Сценарий 1: Детальный просмотр → Редактирование → Возврат
1. Пользователь в детальном просмотре (с медиа)
2. Нажимает "Редактировать" → сохраняется `old_detail_message_id`
3. Открывается меню редактирования (с медиа)
4. При возврате: `edit_media` (медиа → медиа)

### Сценарий 2: Слайдер → Редактирование → Возврат
1. Пользователь в слайдере (с медиа)
2. Нажимает "Редактировать" → сохраняется `old_slider_message_id`
3. Открывается меню редактирования (с медиа)
4. При возврате: `edit_media` (медиа → медиа)

### Сценарий 3: Главное меню → Редактирование → Возврат
1. Пользователь в главном меню (без медиа)
2. Вводит ID товара → нет сохраненных ID
3. Открывается меню редактирования (с медиа)
4. При возврате: `send` новое + удалить старое (без медиа → медиа)

## 🔧 Технические детали

### MessageManager
- Автоматически управляет активным сообщением
- Сохраняет `active_msg_id` в FSM
- Правильно обрабатывает переходы между сообщениями

### Очистка старых ID
```python
# После успешной отправки нового сообщения
await state.update_data(
    old_detail_message_id=None, 
    old_slider_message_id=None
)
```

### Fallback логика
```python
try:
    await callback.message.edit_media(...)
except TelegramBadRequest:
    # Если edit не удался, отправляем новое
    await message_manager.send_photo_message(...)
```
