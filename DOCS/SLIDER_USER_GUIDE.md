# 📱 Слайдер - Руководство пользователя

## 🎯 Что такое слайдер?

Слайдер - это удобный способ просмотра товаров в виде автоматически сменяющихся изображений с возможностью управления просмотром.

## 🚀 Как запустить слайдер

### Из главного меню
1. Нажмите **🛍 Каталог** в главном меню
2. Выберите категорию товаров
3. Слайдер запустится автоматически

### Из избранного
1. Нажмите **❤️** в главном меню (если у вас есть избранные товары)
2. Слайдер покажет только ваши избранные товары

### По размерам
1. Нажмите **🎯** в главном меню (если у вас настроены размеры)
2. Слайдер покажет товары, подходящие вашим размерам

## 🎮 Управление слайдером

### Основные кнопки

| Кнопка | Действие | Описание |
|--------|----------|----------|
| **ᐅ** | Запустить автопроигрывание | Слайды будут сменяться автоматически |
| **||** | Остановить автопроигрывание | Слайдер остановится на текущем слайде |
| **←** | Предыдущий слайд | Переход к предыдущему товару |
| **→** | Следующий слайд | Переход к следующему товару |
| **1/10** | Информация | Показывает текущую позицию в слайдере |

### Дополнительные кнопки

| Кнопка | Действие | Описание |
|--------|----------|----------|
| **➕** | Добавить в корзину | Товар добавляется в вашу корзину |
| **➖** | Убрать из корзины | Товар удаляется из корзины |
| **⭐️** | Добавить в избранное | Товар добавляется в избранное |
| **🤍** | Убрать из избранного | Товар удаляется из избранного |
| **інфо** | Подробная информация | Открывает детальный просмотр товара |
| **╳** | Закрыть | Возврат в главное меню |

## 📋 Детальный просмотр товара

При нажатии кнопки **інфо** открывается детальный просмотр с:

- **Полным описанием** товара
- **Подробными характеристиками**
- **Доступными размерами**
- **Актуальной ценой**
- **Информацией о скидках**

### Навигация в детальном просмотре

| Кнопка | Действие |
|--------|----------|
| **←** | Предыдущее фото товара |
| **→** | Следующее фото товара |
| **← Назад** | Возврат к слайдеру |
| **✏️ Редагувати** | Редактирование товара (только для админов) |

## ⚙️ Настройки слайдера

### Скорость автопроигрывания

Вы можете настроить скорость смены слайдов:

1. Откройте **👤 Профіль**
2. Нажмите **⚙️ Налаштування**
3. Выберите **Слайдер**
4. Выберите скорость: **2 сек**, **3 сек**, **5 сек**

### Персональные настройки

- **Скорость слайдера** сохраняется индивидуально для каждого пользователя
- **Избранные товары** синхронизируются между всеми сессиями
- **Корзина** сохраняется до оформления заказа

## 🛒 Работа с корзиной

### Добавление товаров
- Нажмите **➕** рядом с товаром
- Товар автоматически добавится в корзину
- Кнопка изменится на **➖**

### Удаление товаров
- Нажмите **➖** рядом с товаром
- Товар удалится из корзины
- Кнопка изменится на **➕**

### Просмотр корзины
- В главном меню нажмите **🛍** (показывает количество товаров)
- Или перейдите в **👤 Профіль** → **🛍 Кошик**

## ❤️ Работа с избранным

### Добавление в избранное
- Нажмите **🤍** рядом с товаром
- Товар добавится в избранное
- Звездочка станет **⭐️**

### Удаление из избранного
- Нажмите **⭐️** рядом с товаром
- Товар удалится из избранного
- Звездочка станет **🤍**

### Просмотр избранного
- В главном меню нажмите **❤️** (показывает количество избранных)
- Откроется слайдер только с избранными товарами

## 🎯 Персональные рекомендации

### Настройка размеров
1. Откройте **👤 Профіль**
2. Нажмите **📏 Мої розміри**
3. Укажите ваши размеры для:
   - **Курток**
   - **Джемперов**
   - **Джинсов**

### Просмотр подходящих товаров
- Нажмите **🎯** в главном меню
- Слайдер покажет только товары ваших размеров
- Количество подходящих товаров отображается на кнопке

## 🔍 Фильтрация товаров

### Доступные фильтры
- **Категории**: Куртки, Джемпера, Джинси
- **Бренды**: Все доступные бренды
- **Сезоны**: Лето, Зима, Демисезон
- **Размеры**: Все доступные размеры

### Применение фильтров
1. Нажмите **🔍 Фільтри** в главном меню
2. Выберите нужные параметры
3. Нажмите **Показати**
4. Слайдер запустится с отфильтрованными товарами

## 📊 Статистика просмотров

В вашем профиле отображается статистика:

- **Просмотры в слайдере**

## 🆘 Решение проблем

### Слайдер не запускается
- Проверьте подключение к интернету
- Попробуйте перезапустить бота
- Обратитесь к администратору

### Товары не загружаются
- Убедитесь, что выбранные фильтры корректны
- Попробуйте сбросить фильтры
- Проверьте, есть ли товары в выбранной категории

### Проблемы с корзиной
- Товары автоматически сохраняются
- При проблемах попробуйте перезапустить бота
- Корзина синхронизируется между сессиями

### Проблемы с избранным
- Избранные товары сохраняются автоматически
- При проблемах попробуйте добавить товар заново
- Избранное синхронизируется между устройствами

## 💡 Полезные советы

### Быстрая навигация
- Используйте **ᐅ** для быстрого просмотра всех товаров
- Нажмите **||** для остановки на интересном товаре
- Используйте **←** и **→** для точной навигации

### Эффективный поиск
- Настройте размеры для получения персональных рекомендаций
- Используйте фильтры для сужения поиска

### Работа с корзиной
- Регулярно проверяйте корзину
- Удаляйте ненужные товары
- Используйте корзину для сравнения товаров
