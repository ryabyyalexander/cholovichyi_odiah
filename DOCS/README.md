# CHOLOVICHYI_ODIAH_BOT

Telegram-бот для магазину чоловічого одягу (м. Одеса). Повнофункціональна система автоматизації продажів з розвиненою адмін-панеллю та інтелектуальною навігацією.

## 🎯 Основні функції

### 👤 Для користувачів
- **Реєстрація з номером телефону** - обов'язкова реєстрація для доступу до каталогу
- **Інтелектуальний каталог** - слайдер з автопроіграванням та паузами
- **Детальний перегляд товарів** - фото, опис, ціни, розміри, знижки
- **Розширена фільтрація** - за категоріями, підкатегоріями, розмірами, брендами, сезонами
- **Збереження фільтрів** - персональні налаштування для кожного користувача
- **Анімований інтерфейс** - динамічні підписи та плавні переходи

---

### 🏅 Система лояльності

**Система лояльності** — багаторівнева програма для мотивації покупців, яка автоматично працює для кожного зареєстрованого користувача.

- **Нарахування балів**: за кожну покупку користувач отримує бали (5% від суми замовлення)
- **Використання балів**: можна оплатити до 30% вартості замовлення накопиченими балами
- **Реферальна програма**: за запрошення друга (який зробив перше замовлення) — бонус 100 балів
- **Рівні лояльності**:
  - Bronze (0+ балів)
  - Silver (1000+ балів)
  - Gold (5000+ балів)
  - Diamond (10000+ балів)
- **Автоматичне підвищення рівня**: при досягненні порогу рівня — підвищення, обнулення балів для прогресу до наступного рівня
- **Історія балів**: відображення всіх операцій (нарахування, списання, бонуси)
- **Відображення статусу**: в профілі користувача — поточний рівень, кількість балів, прогрес до наступного рівня
- **Підтримка промокодів, сезонних бонусів, місій** (задел для майбутнього)

**Як це працює для користувача:**
- Після покупки бот запропонує використати бали для знижки
- Після підтвердження — частина балів списується, а нові нараховуються за покупку
- Всі зміни відображаються в історії профілю
- При досягненні нового рівня — бот надсилає вітальне повідомлення

**Приклад відображення в профілі:**
```
Статус: Активний
Рівень: Silver
Бали: 1200
До рівня Gold: 3800 балів
Історія балів: [переглянути]
```

## 🛡️ Система захисту від спаму

Бот має вбудовану систему захисту від повторних кліків та спаму:

### AntiSpamMiddleware
- **Загальна затримка**: 3 секунди між кліками для звичайних кнопок
- **Слайдер**: 1.5 секунди для кнопок `prev`/`next`
- **Пауза/Продовження**: Повне виключення - працюють миттєво
- **Автоочищення**: Видалення старих записів кожну хвилину

### CriticalOperationMiddleware
- **Захист від одночасних операцій** - блокує повторні кліки під час виконання критичних операцій
- **Критичні операції**: редагування товарів, видалення, управління медіа, навігація слайдера
- **Повідомлення користувачу**: "⏳ Операція вже виконується..." при спробі повторного кліку

### Особливості роботи
```
pause/play: Миттєва робота (без затримок)
prev/next: 1.5с затримка + захист від одночасності
Інші кнопки: 3с затримка + захист від одночасності
```

## 🏗️ Архітектура та технології

### Backend
- **Python 3.10+** - основна мова розробки
- **aiogram 3.x** - сучасний фреймворк для Telegram ботів
- **SQLite** - легка та швидка база даних
- **FSM (Finite State Machine)** - управління станами користувача

### Ключові компоненти
- **MessageManager** - інтелектуальне управління повідомленнями
- **SliderManager** - автоматичні слайдери з контролами
- **FilterManager** - система фільтрації з збереженням налаштувань
- **NavigationCallback** - система навігації з breadcrumbs
- **AntiSpamMiddleware** - захист від спаму та повторних кліків
- **CriticalOperationMiddleware** - захист критичних операцій

## 🔧 Правила роботи з повідомленнями

Бот використовує інтелектуальну систему управління повідомленнями:

```
Медиа → Медиа: edit_media (перезаписуємо поточне повідомлення)
Медиа → Без медиа: send нове + видалити старе
Без медиа → Медиа: send нове + видалити старе
Без медиа → Без медиа: edit (редагуємо поточне повідомлення)
```

Детальні правила див. у файлі `RULES.md`.
