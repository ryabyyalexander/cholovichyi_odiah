# Описание последних исправлений

В этом документе описаны последние изменения, внесенные в код бота.

## 1. Исправлена отправка уведомлений администратору при регистрации нового пользователя

**Проблема:** Администратор не получал уведомление, когда новый пользователь регистрировался и отправлял свой номер телефона. Это происходило из-за ошибки в блоке кода, отвечающем за акцию "Золотой старт", которая прерывала выполнение процесса регистрации.

**Решение:** В качестве временной меры, блок кода, связанный с акцией "Золотой старт" в файле `routers/registration_router.py`, был закомментирован. Это позволило восстановить отправку уведомлений администратору.

**Примечание:** Функционал акции "Золотой старт" в данный момент отключен и требует дальнейшей отладки.

## 2. Восстановлено отображение кнопок в меню создания товара

**Проблема:** В меню создания товара отсутствовали кнопки "все фото-один товар" и "каждое фото- 1 товар".

**Решение:** Была исправлена функция `create_keyboard` в файле `keyboards/kb.py`. Проблема заключалась в том, что функция некорректно проверяла количество товаров перед отображением кнопок, что приводило к их скрытию. Теперь эта проверка пропускается для меню создания товара, и кнопки отображаются корректно.
