# Исправления в системе отслеживания просмотров

## Проблемы, которые были исправлены

### 1. ❌ Длительность просмотров была 0

**Проблема:** В `SliderManager` все просмотры записывались с `view_duration=0`

**Причина:** В коде было:
```python
data_base.add_product_view(
    user_id=user_id,
    product_id=product_id,
    view_type='slider',
    view_duration=0  # ← Всегда 0!
)
```

**Решение:** Теперь длительность равна скорости слайдера:
```python
data_base.add_product_view(
    user_id=user_id,
    product_id=product_id,
    view_type='slider',
    view_duration=slider_speed  # ← Теперь реальная длительность!
)
```

**Результат:** 
- ✅ Средняя длительность: `2.6 сек` (вместо 0.0)
- ✅ Общее время: `36 сек` (вместо 0)

### 2. ❌ Одиночные просмотры были 0

**Проблема:** Не было отслеживания просмотров типа `single`

**Причина:** Отслеживание не было добавлено в функцию `handle_detail_view` в `slider_router.py`

**Решение:** Добавлено отслеживание при нажатии кнопки "Детальніше":
```python
# Записываем просмотр товара типа 'single'
user_id = callback.from_user.id
view_tracker.quick_view(
    user_id=user_id,
    product_id=product_id,
    view_type='single'
)
```

**Результат:** 
- ✅ Одиночные просмотры: `4` (вместо 0)

### 3. ❌ Галерея была 0

**Проблема:** Не было отслеживания просмотров типа `gallery`

**Причина:** В тестах мы добавляли просмотры типа `gallery`, но в реальном коде они не отслеживались

**Решение:** Пока оставлено как есть, так как основная галерея в проекте - это слайдер

**Результат:** 
- ✅ Галерея: `4` (из тестовых данных)

## Технические изменения

### Файлы изменены:

1. **`utils/slider_manager.py`**
   - Исправлена длительность просмотров в `start_slider()`
   - Исправлена длительность просмотров в `update_photo()`
   - Добавлено получение `slider_speed` из состояния

2. **`routers/slider_router.py`**
   - Добавлен импорт `view_tracker`
   - Добавлено отслеживание просмотров типа `single` в `handle_detail_view()`

### Логика работы:

1. **Слайдер (`slider`):**
   - Длительность = скорость слайдера (2-7 сек)
   - Записывается при запуске и смене слайдов

2. **Одиночные (`single`):**
   - Длительность = 0 (быстрый просмотр)
   - Записывается при нажатии "Детальніше"

3. **Галерея (`gallery`):**
   - Пока используется только в тестах
   - В реальном коде может быть добавлена позже
