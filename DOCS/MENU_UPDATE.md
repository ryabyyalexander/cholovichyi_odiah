# Обновление меню и роутеров

## Что было добавлено

### 1. Новые пункты меню
В `enums/main_menu_enum.py` добавлены новые пункты в `RegisteredMainMenu`:
- `HELP = "help"` - Довідка (❓)
- `ABOUT = "about"` - Про нас (ℹ️)
- `CONTACTS = "contacts"` - Контакти (📞)

### 2. Новые команды
В `utils/lexicon.py` добавлены команды в `MENU_COMMANDS`:
- `/catalog` - Каталог товарів
- `/filters` - Фільтри
- `/profile` - Особистий кабінет
- `/contacts` - Контакти
- `/about` - Про нас

### 3. Новые роутеры

#### `routers/help_router.py`
- Обработка пункта меню "Довідка"
- Обработка команды `/help`
- Отображает текст помощи из `HELP_TEXT`

#### `routers/about_router.py`
- Обработка пункта меню "Про нас"
- Обработка команды `/about`
- Отображает информацию о магазине

#### `routers/contacts_router.py`
- Обработка пункта меню "Контакти"
- Обработка команды `/contacts`
- Отображает контактную информацию
- Дополнительная кнопка "Зв'язатися з менеджером"

#### `routers/catalog_router.py`
- Обработка команды `/catalog`
- Запускает слайдер с товарами

#### `routers/filters_router.py`
- Обработка команды `/filters`
- Отображает меню фильтров

#### `routers/profile_command_router.py`
- Обработка команды `/profile`
- Переиспользует логику из `profile_router.py`

### 4. Обновления

#### `keyboards/kb.py`
- Обновлена функция `create_main_menu_keyboard()` для размещения 6 кнопок в 2 ряда (3+3)

#### `routers/navigation_router.py`
- Добавлена обработка новых пунктов меню в функции `process_main_menu()`

#### `routers/router.py`
- Добавлены импорты и регистрация новых роутеров

#### `routers/__init__.py`
- Добавлены новые роутеры в список экспорта

## Структура меню

### Главное меню (2 ряда по 3 кнопки)
```
[✅ Каталог] [🔍 Фільтри] [👤 Кабінет]
[❓ Довідка] [ℹ️ Про нас] [📞 Контакти]
```

### Команды бота
- `/start` - Головна сторінка
- `/help` - Довідка та правила
- `/catalog` - Каталог товарів
- `/filters` - Фільтри
- `/profile` - Особистий кабінет
- `/contacts` - Контакти
- `/about` - Про нас

## Функциональность

### Довідка
- Отображает подробную информацию о работе бота
- Система лояльности и реферальная программа
- Настройки слайдера

### Про нас
- Информация о магазине
- Список брендов
- Адрес и режим работы
- Контактная информация

### Контакти
- Полная контактная информация
- Адрес и как добраться
- Социальные сети
- Кнопка связи с менеджером
