# Добавление просмотров к активности пользователя

## Обзор изменений

Теперь каждый просмотр товара автоматически добавляется к активности пользователя. Это позволяет более точно отслеживать вовлеченность пользователей в каталог товаров.

## Что изменилось

### 1. Автоматическое увеличение активности при просмотрах

**Файл:** `data_base/models.py`

**Метод:** `add_product_view()`

```python
def add_product_view(self, user_id: int, product_id: int, media_id: Optional[int] = None, 
                    view_type: str = 'slider', view_duration: int = 0) -> None:
    try:
        # Добавляем запись о просмотре
        self.execute_query(
            "INSERT INTO product_views (user_id, product_id, media_id, view_type, view_duration) "
            "VALUES (?, ?, ?, ?, ?)",
            (user_id, product_id, media_id, view_type, view_duration)
        )
        
        # ✅ НОВОЕ: Добавляем просмотр к активности пользователя
        self.increment_activity_count(user_id, 1)
        
    except sqlite3.Error as e:
        logger.error(f"Error adding product view: {e}")
```

### 2. Новый метод для получения общего количества просмотров

**Файл:** `data_base/models.py`

**Метод:** `get_user_total_views()`

```python
def get_user_total_views(self, user_id: int) -> int:
    """
    Получает общее количество просмотров пользователя.
    
    Args:
        user_id: ID пользователя
        
    Returns:
        Общее количество просмотров
    """
    cursor = self.execute_query(
        "SELECT COUNT(*) FROM product_views WHERE user_id = ?",
        (user_id,)
    )
    result = cursor.fetchone()
    return result[0] if result else 0
```

## Логика работы

### Как считается активность:

1. **Базовая активность** (`restart_count`):
   - Клики по кнопкам
   - Навигация по меню
   - Другие действия пользователя

2. **Просмотры товаров** (`product_views`):
   - Каждый просмотр = +1 к активности
   - Включает все типы: `slider`, `single`, `gallery`

3. **Итоговая активность** = `restart_count + total_views`

### Пример расчета:

```
Пользователь:
- Базовая активность: 10
- Просмотров товаров: 36
- Итоговая активность: 10 + 36 = 46
```

## Влияние на систему лояльности

### Бонусы за активность:

Активность влияет на расчет уровня лояльности:

```python
progress_points = points + (activity / 10) + referral_points
```

Где `activity` теперь включает просмотры товаров.

### Пример влияния:

```
Бронзовый уровень: 0-99 баллов
Серебряный уровень: 100-299 баллов

Пользователь с:
- Баллы лояльности: 50
- Активность (включая просмотры): 46
- Бонус активности: 46 / 10 = 4.6
- Итого: 50 + 4.6 = 54.6 балла

Результат: Остается на бронзовом уровне
```
