# 🛒 Руководство пользователя: Корзина

## Как добавить товар в корзину

### В слайдере товаров
1. Найдите нужный товар в каталоге
2. Нажмите кнопку ➕ рядом с товаром
3. Товар автоматически добавится в корзину
4. Кнопка изменится на ➖ (товар в корзине)

### Выбор размера
- Если у товара есть размеры, сначала выберите нужный размер
- Затем нажмите ➕ для добавления в корзину

## Как просмотреть корзину

### В главном меню
- Нажмите кнопку "🛍 X тов." (где X - количество товаров)
- Откроется детальный просмотр корзины

### В профиле
1. Перейдите в "👤 Особистий кабінет"
2. Нажмите "🛍 Ваш кошик" (если есть товары)

## Управление корзиной

### Удаление отдельных товаров
1. В корзине нажмите "╳ Видалити: ID X [название]"
2. Подтвердите удаление кнопкой "✅ Так, видалити"

### Очистка всей корзины
- Нажмите "❌ Очистити кошик"
- Корзина очистится и вы вернетесь на главную

### Изменение количества
- При повторном добавлении того же товара количество автоматически увеличивается

## Информация в корзине

### Список товаров
- **ID товара** - уникальный номер
- **Категория/подкатегория** - тип товара
- **Название** - полное название товара
- **Размер** - выбранный размер (если есть)
- **Количество** - количество единиц
- **Цена** - цена за единицу в евро

### Скидки и расчеты
- **Скидки на товары** - если есть скидки на отдельные товары
- **Персональная скидка** - автоматический расчет на основе ваших баллов
- **Итоговая сумма** - в евро и гривнах с учетом всех скидок

### Персональная скидка
Рассчитывается на основе:
- **Баллов за покупки** - 30% от суммы потраченных средств
- **Реферальных баллов** - 1% за каждые 100 реферальных баллов
- **Баллов активности** - 10% от активности в боте

## Часто задаваемые вопросы

### Как изменить количество товара?
- Удалите товар и добавьте заново нужное количество
- Или добавьте товар повторно для увеличения количества

### Почему не могу добавить товар?
- Проверьте, выбран ли размер (если товар требует размер)
- Убедитесь, что товар доступен в наличии

### Как работает персональная скидка?
- Скидка рассчитывается автоматически при каждом просмотре корзины
- Чем больше баллов лояльности, тем выше скидка
- Скидка применяется ко всей сумме корзины

### Можно ли сохранить корзину?
- Корзина автоматически сохраняется для каждого пользователя
- Товары остаются в корзине до очистки или оформления заказа

### Что происходит при удалении товара из каталога?
- Товар автоматически удаляется из корзины
- Вы получите уведомление об этом

## Полезные советы

1. **Регулярно проверяйте корзину** - товары могут стать недоступными
2. **Используйте фильтры** - для быстрого поиска нужных товаров
3. **Сохраняйте размеры в профиле** - для быстрого добавления товаров
4. **Следите за скидками** - персональная скидка может меняться

## Поддержка

Если у вас возникли проблемы с корзиной:
1. Попробуйте очистить корзину и добавить товары заново
2. Проверьте подключение к интернету
3. Обратитесь к администратору бота
