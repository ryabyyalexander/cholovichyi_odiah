# Обновление профиля: Статистика просмотров

## Что добавлено

В профиль пользователя добавлена новая кнопка **"📊 Статистика переглядів"**, которая позволяет пользователям просматривать детальную статистику своих просмотров товаров.

## Расположение кнопки

Кнопка находится в профиле пользователя между кнопками размеров и реферальной ссылкой:

```
🧥 Встановити розмір куртки
👕 Встановити розмір трикотажу  
👖 Встановити джинсовий розмір
📊 Статистика переглядів  ← НОВАЯ КНОПКА
🔗 Реферальне посилання
╳
```

## Что показывает статистика

При нажатии на кнопку пользователь видит:

### 📊 Общая статистика
- **Всего просмотров** - общее количество просмотров товаров
- **Уникальных товаров** - количество разных товаров, которые пользователь просматривал
- **Средняя длительность** - среднее время просмотра товара
- **Общее время просмотров** - суммарное время всех просмотров

### 📈 Распределение по типам
- **Слайдер** - просмотры в режиме слайдера
- **Одиночные** - просмотры отдельных товаров
- **Галерея** - просмотры в галерее

### 📋 Последние просмотры
Список последних 5 просмотренных товаров с указанием:
- Типа просмотра (иконка)
- Названия товара
- Длительности просмотра (если была зафиксирована)

## Техническая реализация

### Файлы изменены:
- `routers/profile_router.py` - добавлена кнопка и обработчик

### Новые функции:
- `handle_view_stats()` - обработчик кнопки статистики
- Интеграция с `view_tracker` для получения данных

### Обработка данных:
- Использует существующую систему отслеживания просмотров
- Получает статистику через `view_tracker.get_user_stats()`
- Получает историю через `view_tracker.get_user_view_history()`

## Навигация

- **Кнопка "← Назад до профілю"** - возвращает пользователя в основной профиль
- Статистика отображается в том же сообщении, заменяя содержимое профиля

## Преимущества

1. **Прозрачность** - пользователи видят свою активность
2. **Мотивация** - понимание своего поведения в боте
3. **Аналитика** - возможность отслеживать интересы
4. **Удобство** - быстрый доступ к статистике из профиля
