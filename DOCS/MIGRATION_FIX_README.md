# Исправление ошибки "no such table: main.products_old"

## 🔍 Диагностика проблемы

Ошибка `no such table: main.products_old` возникает при неудачных миграциях базы данных. Это происходит когда процесс миграции прерывается и оставляет базу данных в неконсистентном состоянии.

## ✅ Решение проблемы

### Автоматическое исправление (рекомендуется)

1. **Запустите утилиту исправления:**
   ```bash
   python fix_migration_errors.py
   ```

2. **Следуйте инструкциям утилиты:**
   - Утилита создаст резервную копию
   - Проанализирует состояние базы данных  
   - Предложит очистить битые миграции
   - Исправит проблемы автоматически

### Ручное исправление (если нужно)

1. **Сделайте резервную копию базы данных:**
   ```bash
   cp data_base.db data_base.db.backup
   ```

2. **Подключитесь к базе данных:**
   ```bash
   sqlite3 data_base.db
   ```

3. **Проверьте наличие старых таблиц:**
   ```sql
   .tables
   ```

4. **Удалите старые таблицы (если основная таблица существует):**
   ```sql
   DROP TABLE IF EXISTS products_old;
   DROP TABLE IF EXISTS sales_old;
   ```

5. **Или восстановите из старой таблицы (если основной нет):**
   ```sql
   ALTER TABLE products_old RENAME TO products;
   ```

### Перезапуск с чистой базой данных

Если проблемы серьезные:

1. **Удалите файл базы данных:**
   ```bash
   rm data_base.db
   ```

2. **Перезапустите бот для создания новой базы:**
   ```bash
   python main.py
   ```
