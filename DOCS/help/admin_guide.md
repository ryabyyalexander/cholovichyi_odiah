# Подробное руководство администратора Telegram-бота "CHOLOVICHYI_ODIAH_BOT"

Это руководство предназначено для администраторов бота "CHOLOVICHYI_ODIAH_BOT" и описывает основные функции и особенности работы с административной панелью.

## 1. Обзор административных функций

Бот предоставляет полный набор инструментов для управления магазином:

*   **Управление товарами:** Добавление, редактирование и удаление товаров.
*   **Управление медиафайлами:** Загрузка фотографий/видео, редактирование подписей, установка главного фото для товаров.
*   **Управление размерами:** Добавление и удаление доступных размеров для товаров, а также управление их количеством.
*   **Система скидок:** Установка процентных скидок на товары.
*   **Управление пользователями:** Активация, блокировка пользователей, просмотр их статистики.
*   **Массовая загрузка:** Импорт товаров, включая медиафайлы, для быстрого наполнения каталога.
*   **Детальная статистика:** Аналитика по товарам и пользователям для отслеживания эффективности.

## 2. Работа с административной панелью

Доступ к административной панели осуществляется через специальные команды или кнопки, доступные только для пользователей с правами администратора.

### 2.1. Редактирование товаров

*   Все поля товара (название, описание, цена, категории, бренды и т.д.) доступны для редактирования через интерфейс бота.
*   После внесения изменений убедитесь, что вы сохранили их.

### 2.2. Управление медиафайлами

*   **Загрузка:** Вы можете загружать новые фотографии и видео для товаров.
*   **Редактирование:** Изменяйте подписи к медиафайлам.
*   **Установка главного фото:** Выбирайте, какое изображение будет отображаться как основное для товара в каталоге.
*   Интерфейс управления медиафайлами представлен в виде сетки с возможностью выполнения действий над каждым элементом.

### 2.3. Управление размерами

*   Добавляйте новые размеры для товаров.
*   Удаляйте существующие размеры.
*   Ведется количественный учет наличия каждого размера.

### 2.4. Массовые операции

*   Функция импорта товаров позволяет быстро загружать большое количество позиций в каталог, включая их медиафайлы. Подробности формата импорта уточняйте в соответствующей документации (если применимо).

## 3. Система защиты от спама и критических операций

Бот имеет встроенные механизмы защиты, которые могут влиять на скорость выполнения некоторых административных действий. Важно понимать их работу:

### 3.1. AntiSpamMiddleware

*   **Общая задержка:** Между нажатиями обычных кнопок действует задержка в 3 секунды. Это предотвращает случайные или намеренные множественные клики.
*   **Задержка слайдера:** Для кнопок навигации слайдера (`prev`/`next`) задержка составляет 1.5 секунды.
*   **Мгновенные действия:** Кнопки "Пауза" и "Продолжить" в слайдере работают мгновенно, без задержек.

### 3.2. CriticalOperationMiddleware

*   **Защита от одновременных операций:** Этот механизм блокирует повторные клики во время выполнения критически важных операций.
*   **Критические операции:** К ним относятся: редактирование товаров, удаление товаров, управление медиафайлами, а также навигация по слайдеру.
*   **Сообщение пользователю:** Если вы попытаетесь выполнить критическую операцию повторно, пока предыдущая еще не завершена, бот покажет сообщение "⏳ Операция уже выполняется...". Дождитесь завершения текущей операции.

## 4. Система администраторов и безопасность

*   Бот использует систему разделения прав доступа, что означает, что административные функции доступны только авторизованным администраторам.
*   Это обеспечивает безопасность данных и предотвращает несанкционированный доступ к управлению магазином.
